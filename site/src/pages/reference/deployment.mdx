# Deployment table

Chain **11155111** (Sepolia), deployment id `ensv2-sepolia-2026-07-30`. Mainnet is deliberately absent: ENSv2 is a beta with non-final interfaces, and the plugin refuses any other chain.

These values are never trusted blindly. `mm ensv2 status` re-derives the registry from the Universal Resolver and refuses to run if the table disagrees; the resolver factory's clone target, the adapter's implementation (EIP-1967 slot) and the reverse registrar (root → reverse TLD resolver → v1 registry) are each re-derived on use.
