Provision an ENSv2 agent identity as one resumable job: resolver, registration, ERC-8004 bind, records. Never repeats a paid step.

- **Capabilities:** `wallet-read`, `wallet-submit`  
- **Data access:** `accounts`, `network`  
- **Signs a transaction:** yes, through MetaMask policy (MFA)

**Arguments**

| Name | Required | Description |
|---|---|---|
| `name` | yes | Label or 2LD name to provision (e.g. myagent or myagent.eth) |

**Flags**

| Flag | Description |
|---|---|
| `--years` | Registration length in years (default 1; minimum ≈ 0.08) |
| `--agent-uri` | agentURI — http(s):// or ipfs:// URI of the agent's ERC-8004 registration JSON (required unless --no-identity) |
| `--description` | description text record — ≤160 chars (ENSIP-18) |
| `--url` | url text record — http(s) website (ENSIP-5) |

| `--max-spend` | Spend ceiling in payment-token units (e.g. 8.5); default: the registrar's quote |
| `--resubmit-unconfirmed` | You have confirmed a step recorded as submitted never landed and is not pending; allow it to be sent again |
| `--verify-rpc` | Second, independent RPC URL for the final verification (default: MM_ENSV2_VERIFY_RPC or publicnode) |
| `--chain` | EVM chain id (default 11155111, Sepolia) |

