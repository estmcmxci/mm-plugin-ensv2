# Live on Sepolia

Everything below was executed from a MetaMask Agent Wallet with MFA on every write and then checked independently with `cast` against a public RPC: receipts, decoded calldata, contract reads, and Universal Resolver `resolve()` and `reverse()` calls. Recipe on the [design](/reference/design#verify-it-yourself) page.

## What the run proved

- Detection refuses mainnet and confirms Sepolia ENSv2 on every command.
- A resolver's address is predicted correctly before deployment and attested after.
- Registration lands with the resolver bound, and a real interruption resumed without a duplicate payment.
- An agent is minted and bound in one transaction, and the name's ENSIP-25 link makes it findable.
- Both directions of resolution hold for both wallets.

The full run log with every command's output is kept in the program repository's runbook.
